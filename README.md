# Zion — Design Resort Hotel (template)

A static marketing site for a fictional mountain resort, in English and Ukrainian.
Built as a front-end exercise: scroll animation, a full-bleed hero, galleries,
an article section and a bilingual routing scheme, with no framework.

**Live:** https://leofranco97.github.io/zion-resort-site/

## This is a template, not a real business

Everything in it is placeholder material:

- **Text** is sample copy. See the note at the top of `src/content.mjs`.
- **Figures** are deliberately `00` so nothing reads as a real promise.
- **Contacts** are `+00 00 000 0000` and `hello@example.com`.
- **Every picture** is painted from scratch by `tools/make_images.py` with
  OpenCV and numpy. There are no photographs in this repository.
- **The film** is generated from one of those painted images by `tools/make_film.py`.

It is not affiliated with, endorsed by, or a copy of any real company, and it
carries no real company's name, branding, photography or copy.

## Stack

Plain JavaScript and CSS, built by a short Node script. Runtime libraries:
GSAP (scroll animation), Lenis (smooth scroll), Swiper (galleries).
Fonts are self-hosted open faces via Fontsource.

## Build

```bash
npm install
node build.mjs                                  # -> dist/, paths rooted at /
node tools/pages-build.mjs /zion-resort-site    # -> docs/, paths for GitHub Pages
python3 tools/make_images.py                    # repaints public/img/ (needs opencv-python)
```

`docs/` is what GitHub Pages serves, which is why it is committed.
`dist/` is the local build and is ignored.
